# Explainer Factory — מפעל סרטוני הסבר (3 ביום, אוטומטי, קוד פתוח)

מערכת שמייצרת סרטוני Reels אנכיים (720×1280, 30fps) בסגנון "הולוגרמה תלת־ממדית כחול־סגול + כתוביות בכפסולות לבנות", באנגלית, ומעלה 3 ביום.
**אין תלות ב-Claude / API / שירות בתשלום.** הכול רץ מקומית: Three.js (תלת־ממד) + Chromium, Kokoro (דיבור, קוד פתוח), FFmpeg.

## איך זה עובד
```
storyboard.json ──► קול (Kokoro) ──► timeline ──► רינדור תלת־ממד פריים־פריים (Three.js) ──► FFmpeg (+מוזיקה מתחלפת) ──► mp4
        ▲                                                                                              │
  בנק סטוריבורדים (storyboards/)  או  LLM מקומי (Ollama) שכותב חדשים                       תור ──► העלאה לאינסטגרם דרך התחברות
```
כל סרטון: הוק מפתיע → הסבר צעד־צעד → כרטיס "Follow". מצלמה זזה ברצף, כתוביות קצרות (מילה אדומה להדגשה), תוויות ומספרים צפים, אפקטים (גלים, חלקיקים, קרניים).

## התקנה (פעם אחת, על המחשב שלך)
```bash
cd explainer-factory
./setup.sh
source .venv/bin/activate
```
ערוך את `config.yaml` → `channel:` (שם המשתמש, השם, ואפשר תמונת פרופיל ב-`assets/`).

## בדיקה ראשונה
```bash
python run.py preview storyboards/airtag.json   # דף מגע של כל הסצנות, בשניות
python run.py make storyboards/airtag.json      # סרטון מלא ->  out/videos/airtag.mp4
```
בשרת בלי כרטיס מסך הרינדור לוקח ~5–6 דקות לסרטון. במק עם GPU: `GPU=1 python run.py make ...` מהיר בהרבה.

## 🔌 איפה מחברים את אינסטגרם (התחברות לחשבון, בלי API)
1. ב-`config.yaml`, הקטע `instagram:` — שנה `enabled: true`.
2. התחברות חד־פעמית:
   ```bash
   python run.py ig-login
   ```
   ייפתח חלון דפדפן. התחבר לחשבון בעצמך (כולל אימות דו־שלבי). ברגע שההתחברות מצליחה — ה-session נשמר בתיקייה `.ig_profile/` והמערכת משתמשת בו מעכשיו.
   *אופציה:* ליצור קובץ `.env` עם `IG_USER=...` ו-`IG_PASS=...` כדי שהטופס יתמלא לבד (עדיין ייתכן שתצטרך לאשר 2FA).
3. בדיקת העלאה **בלי לפרסם**: `python run.py ig-post out/videos/airtag.mp4 "test"` (כל עוד `dry_run: true` זה עוצר לפני "Share" ושומר צילום מסך ב-`out/logs/`).
4. כשהכול נראה טוב: `dry_run: false`.
5. הפעלה קבועה: `python run.py serve` (או `python run.py install-service` — מתחיל אוטומטית עם המחשב).

שעות הפרסום: `schedule.times` ב-`config.yaml` (ברירת מחדל 09:30, 14:30, 19:30). הסרטונים מרונדרים מראש כך שרינדור איטי לא מפספס שעה.

> ⚠️ העלאה אוטומטית דרך דפדפן נוגדת את תנאי השימוש של אינסטגרם ועלולה לגרום לחסימת החשבון או לבקשות אימות. מומלץ להתחיל עם `dry_run`, חשבון שהתחממת בו ידנית, ו-1–2 סרטונים ביום בשבוע הראשון. בלי `enabled: true` המערכת עדיין מייצרת את הסרטונים ומשאירה אותם ב-`out/videos/` להעלאה ידנית.
> **לא נבדק מול אינסטגרם אמיתי** — הסביבה שבה נבנה הקוד חסומה לאינסטגרם. ייתכן שצריך לתקן סלקטורים (`pipeline/instagram.py`) אם הממשק השתנה.

## תוכן: כמה סרטונים יש, ומה קורה כשנגמר
* בנק מוכן: `storyboards/` — 6 סרטונים (מדיח, מצב טיסה, AirTag, Wi-Fi, מיקרוגל, אוזניות מבטלות רעשים) = יומיים.
* **ללא הגבלה:** התקן [Ollama](https://ollama.com) (חינם, מקומי), `ollama pull qwen2.5:14b-instruct`, ו-`llm.enabled: true`. המערכת תיקח נושאים מ-`topics.txt` (40 רעיונות, אפשר להוסיף), תכתוב סטוריבורד, **תריץ אותו דרך מנוע הרינדור כבדיקה** ותנסה שוב אם נשבר. בלי LLM — אחרי 6 סרטונים נגמר התוכן וההודעה `OUT OF CONTENT` תופיע בלוג.
* לכתיבת סטוריבורד ידנית: `pipeline/spec.py` מתעד את כל אבני הבניין (אובייקטים, מצלמה, אפקטים). אפשר להעתיק אותו לכל צ'אט ולבקש סטוריבורד חדש.

## מבנה
`engine/` רינדור תלת־ממד · `pipeline/` קול, תזמון, מוזיקה, הרכבה, תור, אינסטגרם · `storyboards/` תוכן · `config.yaml` הכול ניתן לשינוי · `run.py` שורת פקודה (`make`, `preview`, `gen`, `queue`, `serve`, `ig-login`, `ig-post`, `status`, `install-service`).
